# Financial AI Agent — Excel Add-in

An AI-powered Excel add-in that builds financial models (3-Statement, DCF, LBO)
and references the exact cells used in its calculations.

## Tech Stack
- Excel Add-in (Office.js)
- Node.js + Express + TypeScript backend
- Ollama (local) / Groq (cloud) AI inference
- Yahoo Finance, SEC EDGAR, FRED data sources
